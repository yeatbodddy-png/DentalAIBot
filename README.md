# 🦷 Dental Clinic AI Assistant Bot (`DentalBot`)

Многофункциональный коммерческий Telegram-бот для стоматологической клиники в г. Алматы с поддержкой искусственного интеллекта (Groq API), векторным поиском по базе знаний (RAG на ChromaDB), интеграционным слоем с CRM, полной асинхронностью на `async/await`, мультимодальностью (текст, изображения, голосовые сообщения), умным калькулятором цен в тенге, интерактивной онлайн-записью, сбором контактов пациентов и защищенной панелью администратора (ресепшена).

---

## 🚀 Основные возможности

- **⚡ Полная асинхронность (`async/await`):** Обработчики сообщений, работа с базой данных, CRM-синхронизация и опрос Telegram построены на корутинах (`asyncio`), а синхронные вызовы к Groq и векторному поиску вынесены в фоновые потоки через `run_in_executor`, чтобы бот не подвисал под нагрузкой.
- **🧠 Роли с контекстом:** Переключение между ролями **Администратора** (помощь по прайсу, ценам, услугам) и **Врача-консультанта** (медицинские ответы и рекомендации).
- **🔍 Векторный поиск знаний (RAG):** Подтягивание релевантных данных о клинике, услугах и специалистах из локальной векторной базы **ChromaDB** с ленивой инициализацией без блокировки запуска бота.
- **🧮 Умный расчет стоимости:** Бот знает прайс-лист клиники в **казахстанских тенге (₸)** и помогает складывать стоимость нескольких услуг при комплексном лечении.
- **📍 Локализация:** Привязан к реальному адресу клиники в городе **Алматы** (ул. Абая 150).
- **📋 Интерактивное меню услуг:** Отправка `.webp` изображения прайс-листа с подробным текстовым описанием категорий.
- **📅 Интерактивная онлайн-запись и CRM:** 
  - Получение доступных слотов и синхронизация создания/отмены бронирований через модуль `crm_service.py`.
  - Выбор врача со специализацией и свободного времени через инлайн-кнопки.
  - **Сбор контактов:** Быстрый сбор номеров телефонов пациентов в один клик через Telegram-кнопку `request_contact` или вводом цифр.
  - **Защита от двойного бронирования (Double Booking):** занятые слоты автоматически исчезают из расписания для других пользователей в реальном времени.
- **🔒 Панель администратора (Ресепшен):**
  - Скрытая команда `/admin` доступна только сотрудникам клиники по защищенному списку `ADMIN_IDS`.
  - Просмотр активных записей с отображением реальных имен, `@username` и контактных телефонов пациентов.
  - Возможность отмены записи в один клик с **мгновенным освобождением слота** в общем расписании, синхронизацией с CRM и **автоматической отправкой уведомления пациенту**.
- **🎤 Голосовые сообщения (Whisper):** Распознавание аудиосообщений с помощью модели `whisper-large-v3-turbo` от Groq.
- **🧹 Управление памятью:** Возможность сбросить контекст диалога командой `/reset`.
- **🛡️ Устойчивая доставка ответов:** Безопасная отправка длинных ответов с fallback на обычный текст, если Telegram отклоняет Markdown-разметку.

## 🛠 Технологии и стек

- **Язык:** Python 3.10+ (`asyncio`, `async/await`)
- **Базы данных и поиск:**
  - **SQLite (`aiosqlite`)** (`clinic.db`) — асинхронное хранение записей пациентов, номеров телефонов и занятых слотов с защитой от двойного бронирования и поддержкой `AUTOINCREMENT`.
  - **ChromaDB** + `sentence-transformers` (`all-MiniLM-L6-v2`) — локальная векторная база знаний для RAG-поиска по данным клиники.
- **Библиотеки:** 
  - `pyTelegramBotAPI` (`AsyncTeleBot`) — асинхронное управление Telegram-ботом, инлайн-интерфейсом и правами доступа.
  - `aiosqlite` — неблокирующий доступ к СУБД SQLite.
  - `Groq API` — языковые модели (`qwen/...`, `openai/gpt-oss-...`, `llama-...` и др.) и модель распознавания речи `whisper-large-v3-turbo`.
  - `python-dotenv` — безопасное управление переменными окружения.

DentalBot/
│
├── main.py            # Точка входа, асинхронная инициализация БД/моделей и запуск поллинга
├── handlers.py        # Асинхронные обработчики команд, кнопок, записи, телефона, ГС, текста и админ-панели

├── crm_service.py     # Сервисный слой CRM (получение слотов и синхронизация броней/отмен)

├── dental_data.py     # База знаний клиники (прайс, врачи, расписание, контакты)
├── utils.py           # Вспомогательные утилиты и асинхронная безопасная отправка сообщений
├── config.py          # Конфигурация, загрузка ключей, ID администраторов и системные промпты
├── photos/            # Медиа-файлы (прайс-лист в формате .webp)
├── chroma_db/         # Локальное хранилище векторной базы ChromaDB (создается автоматически)
├── clinic.db          # Файл базы данных SQLite (создается автоматически)
├── .env.example       # Шаблон конфигурационного файла
└── .gitignore         # Игнорируемые файлы (защита токенов, БД, векторов и кэша)
