# 🦷 Dental Clinic AI Assistant Bot (`DentalBot`)

Многофункциональный коммерческий Telegram-бот для стоматологической клиники в г. Алматы с поддержкой искусственного интеллекта (Groq API), мультимодальностью (текст, `.webp` изображения, голосовые сообщения), умным калькулятором цен в тенге, интерактивной онлайн-записью, сбором контактов пациентов и защищенной панелью администратора (ресепшена).

---

## 🚀 Основные возможности

- **🧠 Роли с контекстом:** Переключение между ролями **Администратора** (помощь по прайсу, ценам, услугам) и **Врача-консультанта** (медицинские ответы и рекомендации).
- **🧮 Умный расчет стоимости:** Бот наизусть знает полный прайс-лист клиники в **казахстанских тенге (₸)** и умеет складывать стоимость нескольких услуг при комплексном лечении.
- **📍 Локализация:** Привязан к реальному адресу клиники в городе **Алматы** (ул. Абая 150).
- **📋 Интерактивное меню услуг:** Отправка `.webp` изображения прайс-листа с подробным текстовым описанием категорий.
- **📅 Интерактивная онлайн-запись и CRM:** 
  - Выбор врача со специализацией и свободного времени через инлайн-кнопки.
  - **Сбор контактов:** Быстрый сбор номеров телефонов пациентов в один клик через Telegram-кнопку `request_contact`.
  - **Защита от двойного бронирования (Double Booking):** занятые слоты автоматически исчезают из расписания для других пользователей в реальном времени.
- **🔒 Панель администратора (Ресеппешн):**
  - Скрытая команда `/admin` доступна только сотрудникам клиники по защищенному списку `ADMIN_IDS`.
  - Просмотр активных записей с отображением реальных имен, `@username` и контактных телефонов пациентов.
  - Возможность отмены записи в один клик с **мгновенным освобождением слота** в общем расписании и **автоматической отправкой уведомления пациенту**.
- **🎤 Голосовые сообщения (Whisper):** Распознавание аудиосообщений с помощью модели `whisper-large-v3-turbo` от Groq.
- **🧹 Управление памятью:** Возможность сбросить контекст диалога командой `/reset`.

---

## 🛠 Технологии и стек

- **Язык:** Python 3.10+
- **База данных:** SQLite (`clinic.db`) — постоянное хранение записей пациентов, номеров телефонов и занятых слотов с поддержкой `AUTOINCREMENT`.
- **Библиотеки:** 
  - `pyTelegramBotAPI` (TeleBot) — для управления Telegram-ботом, инлайн-интерфейсом и правами доступа.
  - `Groq API` — сверхбыстрые языковые модели (`llama-3.3-70b` и др.) и модель распознавания речи `whisper-large-v3-turbo`.
  - `python-dotenv` — безопасное управление переменными окружения.
