# 🦷 Dental Clinic AI Assistant Bot (`DentalBot`)

Многофункциональный Telegram-бот для коммерческой стоматологической клиники с поддержкой искусственного интеллекта (Groq API), мультимодальностью (текст, `.webp` изображения, голосовые сообщения), умным калькулятором цен в тенге и интерактивной онлайн-записью.

---

## 🚀 Основные возможности

- **🧠 Роли с контекстом:** Переключение между ролями **Администратора** (помощь по прайсу, ценам, услугам) и **Врача-консультанта** (медицинские ответы и рекомендации).
- **🧮 Умный расчет стоимости:** Бот наизусть знает полный прайс-лист клиники в **казахстанских тенге (₸)** и умеет складывать стоимость нескольких услуг при комплексном лечении.
- **📍 Локализация:** Привязан к реальному адресу клиники в городе **Алматы** (ул. Абая 150).
- **📋 Интерактивное меню услуг:** Отправка `.webp` изображения прайс-листа с подробным текстовым описанием категорий (Терапия, Хирургия, Ортопедия, Ортодонтия).
- **📅 Онлайн-запись:** Интерактивная система записи пациентов через инлайн-кнопки (выбор врача со специализацией, выбор свободного времени, подтверждение).
- **🎤 Голосовые сообщения (Whisper):** Распознавание аудиосообщений с помощью модели `whisper-large-v3-turbo` от Groq (ультра-удобно для пожилых пациентов).
- **🧹 Управление памятью:** Возможность сбросить контекст диалога командой `/reset`.

---

## 🛠 Технологии и стек

- **Язык:** Python 3.10+
- **Библиотеки:** 
  - `pyTelegramBotAPI` (TeleBot) — для управления Telegram-ботом и инлайн-интерфейсом.
  - `Groq API` — сверхбыстрые языковые модели (`llama-3.3-70b` и др.) и модель распознавания речи `whisper-large-v3-turbo`.
  - `python-dotenv` — безопасное управление переменными окружения.
